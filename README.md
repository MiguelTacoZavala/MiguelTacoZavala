## 🚀 Featured Projects

### [Movi](https://github.com/MiguelTacoZavala/Movi)

Web platform for managing a dance academy, including class scheduling, reservations, user roles, payments and administration. I developed the client-facing module: class booking with interactive seat selection, reservation history and credit management; integrated a Yape payment gateway with a seat-hold and payment-confirmation flow; and implemented profile image uploads via a cloud storage service.

**Tech:** React · Node.js · Express · Prisma · MySQL

### [Patitas Sanas](https://github.com/KevinBohorquez/PatitasSanas)

Management system for veterinary clinics, covering client and pet intake, triage, medical consultations, clinical history, appointment scheduling with automated email reminders, cash flow tracking and PDF reporting, with role-based dashboards. Collaborative academic project — my contribution was mainly on the frontend.

**Tech:** Python · FastAPI · React · MySQL

### [Marketing CRM](https://github.com/mrcastilla8/Marketing-CRM)

Email marketing module within an enterprise CRM, built with a 6-person team. I designed the module's database schema, ensuring referential integrity and data consistency, and integrated external services and webhooks for real-time delivery status monitoring. *(Contributed via a previous institutional GitHub account, no longer in use.)*

**Tech:** React · Node.js · MySQL
